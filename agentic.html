🤖 What is Agentic AI?

Agentic AI is an AI system that acts autonomously to accomplish complex, multi-step goals — not just answering questions, but actually doing things.

1
🎯

Sets Goals

Understands high-level objective, breaks it into subtasks automatically.

2
🗺️

Plans Steps

Creates a sequence of actions — like a human project manager.

3
🔧

Uses Tools

Web search, code runners, APIs, databases — any tool it needs.

4
💾

Has Memory

Short-term (context) and long-term (vector DB) across all steps.

5
🔄

Self-Corrects

Evaluates its own output, detects errors, tries again.

6
✅

Delivers Work

Returns completed tasks — not just an answer, but done work.

🗂️ Types of AI Agents
🎯

Goal-Based

Specific objective, plans to reach it, stops when done. Example: Research assistant.

🔁

Reflexive

Reacts with if-then rules. No memory. Fast. Example: Rule-based bot.

🌍

Model-Based

Maintains world model. Reasons about unseen states. Example: Self-driving AI.

💰

Utility-Based

Maximizes reward. Picks best action. Example: Trading bot.

📚

Learning Agent

Improves from RL or RLHF. Example: Game-playing AI.

🤝

Multi-Agent

Specialists collaborate. Orchestrator delegates. Example: AutoGen crews.

CH 3 · PYTHON
🧠 CONNECT TO LLM
ChatOpenAI, streaming, chat history, prompt templates
 llm.py
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage
from langchain.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o", temperature=0)

# 1. Simple call
print(llm.invoke("Explain AI agents in one sentence.").content)

# 2. Multi-turn chat history
msgs = [SystemMessage("You are an AI expert."),
HumanMessage("What is LangGraph?")]
print(llm.invoke(msgs).content)

# 3. Real-time streaming
for chunk in llm.stream("Write a haiku about AI agents"):
print(chunk.content, end="", flush=True)

# 4. Prompt template with variables
chain = ChatPromptTemplate.from_template("You are a {role}. Answer: {q}") | llm
chain.invoke({"role":"Python expert","q":"What is FAISS?"})
✅ CH 3 DONE
  • ChatOpenAI = LLM wrapper with temperature control
  • SystemMessage + HumanMessage = multi-turn history
  • .stream() = real-time token streaming
  • Prompt templates = reusable parameterized prompts
CH 4 · PYTHON
🔧 TOOLS & FUNCTION CALLING
@tool decorator, web search, custom tools, bind_tools
 tools.py
from langchain_core.tools import tool
from langchain_community.tools import DuckDuckGoSearchRun

@tool
def get_weather(city: str) -> str:
"""Get current weather for a city."""
return f"Weather in {city}: 22°C, Sunny ☀️"

@tool
def calculate(expression: str) -> str:
"""Evaluate a math expression safely."""
try: return str(eval(expression))
except: return "Error in expression"

search = DuckDuckGoSearchRun() # free, no API key!
tools = [get_weather, calculate, search]

# Bind tools to LLM — it now decides which to call
llm_tools = llm.bind_tools(tools)
r = llm_tools.invoke("What is 42 × 17?")
print(r.tool_calls) # [{name:'calculate', args:{expression:'42*17'}}]
✅ CH 4 DONE
  • @tool + docstring = AI-callable Python function
  • DuckDuckGoSearchRun = free web search, zero setup
  • llm.bind_tools() wires all tools to the LLM
  • LLM returns tool_calls list — you execute them
CH 5 · PYTHON
💾 MEMORY SYSTEMS
FAISS vector store, OpenAI Embeddings, MemorySaver for agent sessions
 memory.py
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langgraph.checkpoint.memory import MemorySaver

# 1. Embeddings: text → vector
emb = OpenAIEmbeddings(model="text-embedding-3-small")

# 2. FAISS in-memory vector store
vs = FAISS.from_texts(["Agents use ReAct loops.", "LangGraph builds stateful agents."], emb)

# 3. Semantic search
docs = vs.similarity_search("What is a ReAct pattern?", k=2)
print(docs[0].page_content)

# 4. MemorySaver = agent conversation memory
memory = MemorySaver()
config = {"configurable": {"thread_id": "user-session-1"}}
# pass to agent: create_react_agent(..., checkpointer=memory)
✅ CH 5 DONE
  • OpenAIEmbeddings converts text to 1536-dim vectors
  • FAISS.from_texts = instant local vector store
  • MemorySaver gives agents persistent cross-turn memory
  • thread_id separates different user sessions cleanly
CH 6 · PYTHON
🔍 RAG INTEGRATION
Load PDFs, chunk text, embed into FAISS, create retriever tool for agent
 rag.py
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain.tools.retriever import create_retriever_tool

# 1. Load PDF
docs = PyPDFLoader("knowledge.pdf").load()

# 2. Split into overlapping chunks
chunks = RecursiveCharacterTextSplitter(chunk_size=512, chunk_overlap=64).split_documents(docs)

# 3. Embed & store in FAISS
vs = FAISS.from_documents(chunks, OpenAIEmbeddings())
retriever = vs.as_retriever(search_kwargs={"k":4})

# 4. Wrap as agent tool
rag_tool = create_retriever_tool(retriever,
name="search_docs",
description="Search internal knowledge base documents")
tools = [rag_tool, search] # RAG + web search
✅ CH 6 DONE
  • PyPDFLoader → RecursiveCharacterTextSplitter → FAISS
  • create_retriever_tool wraps retriever as agent tool
  • Agent now picks: search_docs OR web_search
CH 7 · PYTHON
♻️ FULL REACT AGENT
create_react_agent from LangGraph — combines everything built so far
 agent.py
from langgraph.prebuilt import create_react_agent
from langchain_core.messages import HumanMessage

# Build agent with ALL tools + memory
agent = create_react_agent(
llm,
tools=[rag_tool, search, get_weather, calculate],
checkpointer=memory
)

# Run — agent loops automatically until done
config = {"configurable": {"thread_id": "user-1"}}
resp = agent.invoke({"messages": [HumanMessage("What does our refund policy say?")]}, config)
print(resp["messages"][-1].content)

# Auto flow: Think→search_docs→Observe→Think→Answer
✅ CH 7 DONE
  • create_react_agent = full ReAct loop in one function call
  • Pass all tools as a list — agent picks automatically
  • MemorySaver + thread_id = persistent per-user memory
  • Agent handles Think→Act→Observe loop internally
CH 8 · PYTHON
🤝 MULTI-AGENT SYSTEM
LangGraph StateGraph: Researcher → Writer → Critic crew
 crew.py
from langgraph.graph import StateGraph, END
from typing import TypedDict

class State(TypedDict): messages: list

# Three specialist agents
researcher = create_react_agent(llm, [search, rag_tool])
writer = create_react_agent(llm, [])
critic = create_react_agent(llm, [])

def research_node(s): return researcher.invoke(s)
def write_node(s): return writer.invoke(s)
def critic_node(s): return critic.invoke(s)

g = StateGraph(State)
g.add_node("researcher", research_node)
g.add_node("writer", write_node)
g.add_node("critic", critic_node)
g.add_edge("researcher", "writer")
g.add_edge("writer", "critic")
g.add_edge("critic", END)
g.set_entry_point("researcher")
crew = g.compile()
✅ CH 8 DONE
  • StateGraph = workflow with typed state passed between agents
  • Each node = specialist agent with own tools
  • Edges define flow: Researcher → Writer → Critic → END
  • .compile() returns a runnable pipeline

using Microsoft.SemanticKernel;
using Microsoft.SemanticKernel.ChatCompletion;

var kernel = Kernel.CreateBuilder()
.AddOpenAIChatCompletion("gpt-4o", config["OpenAI:ApiKey"]!)
.AddOpenAITextEmbeddingGeneration("text-embedding-3-small", config["OpenAI:ApiKey"]!)
.Build();

CH 4 · .NET
🔧 PLUGINS & FUNCTION CALLING
[KernelFunction], [Description], register plugins, auto function calling
 WeatherPlugin.cs
using Microsoft.SemanticKernel;
using System.ComponentModel;

public class MyPlugins
{
[KernelFunction]
[Description("Get current weather for a city")]
public string GetWeather(string city) => $"Weather in {city}: 22°C ☀️";

[KernelFunction]
[Description("Evaluate a math expression")]
public string Calculate(string expression) => "Result: 714";
}

// Register plugin
kernel.Plugins.AddFromObject(new MyPlugins(), "Tools");

// Enable auto function calling
var settings = new OpenAIPromptExecutionSettings
{ ToolCallBehavior = ToolCallBehavior.AutoInvokeKernelFunctions };

var r = await kernel.InvokePromptAsync(
"What is 42×17 and weather in London?",
new KernelArguments(settings));
✅ CH 4 DONE
  • [KernelFunction] + [Description] = @tool equivalent in C#
  • kernel.Plugins.AddFromObject() registers the class
  • AutoInvokeKernelFunctions = bind_tools() equivalent

🔍 RAG INTEGRATION

using UglyToad.PdfPig;
using Microsoft.SemanticKernel.Text;

// 1. Load PDF + chunk
var text = string.Join(" ", PdfDocument.Open("doc.pdf").GetPages().Select(p => p.Text));
var chunks = TextChunker.SplitPlainTextParagraphs(TextChunker.SplitPlainTextLines(text, 80), 300, 40);
for(int i=0; i<chunks.Count; i++)
await memory.SaveInformationAsync("docs", chunks[i], $"chunk-{i}");

// 2. RAG plugin the agent can call
public class RagPlugin(ISemanticTextMemory mem)
{
[KernelFunction, Description("Search knowledge base")]
public async Task<string> SearchAsync(string query)
{
var r = await mem.SearchAsync("docs", query, limit:4).ToListAsync();
return string.Join("\n---\n", r.Select(x => x.Metadata.Text));
}
}
kernel.Plugins.AddFromObject(new RagPlugin(memory), "KB");

CH 8 · .NET
🤝 MULTI-AGENT SYSTEM
AgentGroupChat — Researcher + Writer + Critic with auto-termination
 MultiAgent.cs
using Microsoft.SemanticKernel.Agents;
using Microsoft.SemanticKernel.Agents.Chat;

ChatCompletionAgent researcher = new() {Name="Researcher",Instructions="Research thoroughly.",Kernel=kernel};
ChatCompletionAgent writer = new() {Name="Writer", Instructions="Write clear content.", Kernel=kernel};
ChatCompletionAgent critic = new() {Name="Critic", Instructions="Say APPROVED if good.",Kernel=kernel};

AgentGroupChat group = new(researcher, writer, critic)
{
ExecutionSettings = new()
{
SelectionStrategy = new SequentialSelectionStrategy(),
TerminationStrategy = new KernelFunctionTerminationStrategy(
AgentGroupChat.CreateTerminationFunction("Critic","APPROVED"), kernel)
}
};
await foreach(var m in group.InvokeAsync())
Console.WriteLine($"[{m.AuthorName}]: {m.Content}");
✅ CH 8 DONE
  • AgentGroupChat = StateGraph equivalent in .NET
  • SequentialSelectionStrategy = round-robin agent rotation
  • Stops automatically on APPROVED keyword from Critic
