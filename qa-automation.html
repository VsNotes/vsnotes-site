CH 3 · PYTHON
🎭 YOUR FIRST PLAYWRIGHT TESTS
Page Object Model pattern, writing clean tests, assertions, screenshots on failure.
🎭Playwright says:

The Page Object Model (POM) keeps your tests clean. Each page of your app = one Python class. Tests call the class methods, never raw selectors. When the UI changes, you update one class, not 50 tests!

from playwright.sync_api import Page class LoginPage: def __init__(self, page: Page): self.page = page self.username = page.get_by_label("Username") # semantic selector! self.password = page.get_by_label("Password") self.btn_login = page.get_by_role("button", name="Login") def login(self, user: str, pwd: str): self.page.goto("/login") self.username.fill(user) self.password.fill(pwd) self.btn_login.click() def is_logged_in(self) -> bool: return self.page.url.endswith("/dashboard")
🌟
Use get_by_role, get_by_label, get_by_text instead of CSS selectors like #submit-btn. Semantic selectors are self-healing — they find the element by what it does, not where it is in the DOM!

CH 5 · PYTHON
🔧 SELF-HEALING SELECTORS
Build an AI layer that detects broken selectors and automatically finds the right element using semantic matching.
🔧Self-Heal Bot:

When a selector breaks (button moved, ID changed, CSS class renamed), instead of failing, our agent takes a screenshot, sends it to GPT-4o Vision, asks "where is the Submit button?", and gets the new selector back automatically!

import base64 from langchain_openai import ChatOpenAI vision_llm = ChatOpenAI(model="gpt-4o") def heal_selector(page, broken_selector: str, element_purpose: str) -> str: # Take screenshot, ask AI to find the element screenshot = page.screenshot() img_b64 = base64.b64encode(screenshot).decode() response = vision_llm.invoke([{"type":"image_url","image_url":{"url":f"data:image/png;base64,{img_b64}"}}, {"type":"text","text":f"The selector '{broken_selector}' broke. Find '{element_purpose}'. Return only the new Playwright selector."}]) return response.content.strip() # Returns: 'get_by_role("button", name="Submit Order")' — and test continues!
✅ CH 5 DONE
  • GPT-4o Vision analyzes screenshots to find moved elements
  • heal_selector() returns a working Playwright selector automatically
  • Wrap all page interactions in a try/heal pattern for resilient tests

public async Task<string> HealSelectorAsync(IPage page, string purpose) { // 1. Take screenshot as base64 var screenshotBytes = await page.ScreenshotAsync(); var b64 = Convert.ToBase64String(screenshotBytes); // 2. Ask GPT-4o Vision to find the element var prompt = $"Find the '{purpose}' element. using Microsoft.SemanticKernel.Planning; // Register all QA plugins kernel.Plugins.AddFromType<BrowserPlugin>("browser"); // navigates & screenshots kernel.Plugins.AddFromType<TestGenPlugin>("testgen"); // generates test code kernel.Plugins.AddFromType<TestRunnerPlugin>("runner"); // runs dotnet test kernel.Plugins.AddFromType<HealerPlugin>("healer"); // fixes broken selectors kernel.Plugins.AddFromType<BugReporterPlugin>("bugs"); // creates GitHub Issues // Run the autonomous planner — it decides the steps! var planner = new FunctionCallingStepwisePlanner(); var result = await planner.ExecuteAsync(kernel, "Fully test the /checkout page, generate tests, run them, file bugs for failures"); Console.WriteLine(result.FinalAnswer); // Output: "Found 3 bugs, filed GitHub Issues #42 #43 #44, coverage: 87%"
